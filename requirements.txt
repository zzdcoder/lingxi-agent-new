# ============================================
# 1. RAG / LLM 核心框架（LangChain 生态）
# ============================================
# LangChain 核心库，提供 Chain、Prompt、OutputParser、消息类型等基础抽象与编排能力
langchain-core
# LangChain 主包，提供 ConversationChain、ConversationBufferMemory 等高级组件
langchain
# LangChain 社区组件库，集成大量第三方工具、向量库、文档加载器等扩展组件
langchain-community
# LangChain 对 OpenAI 的官方适配，支持 GPT 系列模型调用、Embedding 生成、流式输出
langchain-openai
# LangChain 对 Chroma 向量数据库的集成封装，支持向量检索与存储的链式调用
langchain-chroma

# ============================================
# 2. 文档解析与文本处理
# ============================================
# PDF 文件解析库，支持提取 PDF 中的文本、元数据，用于知识库文档加载
pypdf
# 中文分词库，支持中文文本的精准/全模式分词、关键词提取，常用于中文 BM25 检索预处理
jieba

# ============================================
# 3. Embedding 与向量检索
# ============================================
# 预训练句向量模型库，支持将文本编码为稠密向量，用于语义相似度计算与向量检索
sentence-transformers
# 经典稀疏检索算法实现，基于词频统计对文档进行相关性排序，常与向量检索混合使用（Hybrid RAG）
rank-bm25
# 轻量级开源向量数据库，支持向量存储、相似度检索、元数据过滤，是本地 RAG 的常用选择
chromadb
